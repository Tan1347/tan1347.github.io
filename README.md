# CDN测速工具
------
本文为CDN测速工具的使用说明

## 项目简介
CDN测速工具是一个基于Web的多线程下行流量测试工具，通过循环下载资源文件来消耗下行流量，可用于网络测速、CDN节点质量验证，或增加下行流量使用以避免运营商PCDN误判。

## 功能特性
- 多线程并发下载，可自定义线程数
- 支持无限循环模式
- 实时显示下载速度、已消耗流量、运行时长
- 支持自定义下载链接
- 内置多个CDN节点供选择

## 部署说明
本项目为纯静态前端项目，可部署到任何静态文件托管平台（如 GitHub Pages、阿里云 OSS、腾讯云 COS 等）。

1. 下载或克隆本仓库
2. 将文件部署到站点目录
3. 访问 `index.html` 即可使用
